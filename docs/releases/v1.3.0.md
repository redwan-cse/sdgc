## 2. Release Highlights & Deliverables

### 2.1 Enhanced Contact Page & Inquiries Hub

- **Modern Two-Column Card Architecture**: Transformed `/contact` into a responsive dual-column layout featuring high-contrast typography, brand accents, and structured club details.
- **Audience Persona Selection ("I am a...")**: Filter inquiries by visitor persona: _Prospective Member_, _Current Member_, _Garden Walk Visitor_, _Press / Media_, _Community Partner / Sponsor_, or _General Inquirer_.
- **Categorized Inquiry Routing**: Inquiries classified by topic: _Membership Inquiry_, _Garden Walk Information_, _Civic Projects & Volunteering_, _Event Details & Registration_, _Website & Portal Support_, or _General Question_.
- **Real-Time 0/1000 Character Counter**: Dynamic message length indicator with visual warning when approaching the threshold.
- **Attachment URL Field**: Dedicated field for document, PDF, flyer, or photo URLs relevant to the inquiry.
- **Automated Honeypot & Bot Protection**: Invisible `website_url` honeypot field catches automated submission attempts silently without disrupting human users.
- **Response Expectation Pill**: Prominent notification badge setting expectations ("We typically respond within 24–48 business hours").
- **Local Saugatuck–Douglas Heritage Context**: Rich contact sidecard highlighting 501(c)(3) non-profit status, 1928 heritage badge, regular meeting location (Old School House, Douglas, MI), social links, and an interactive full-width Google Map of the historic Saugatuck–Douglas region.
- **Admin Inquiries Inbox Upgrade**: Updated `/admin/messages` with persona badges, topic filters, subject lines, and clickable attachment links for administrative staff.

### 2.2 In-Dashboard Password Change

- **Re-Authentication Guard**: Requires verification of the user's current password via Supabase Auth before permitting credential updates.
- **Double New Password Validation**: Enforces matching new password entries with strong complexity requirements (minimum 8 characters, uppercase, lowercase, numbers).
- **Audit Logging**: Successful password changes emit structured audit logs (`audit_logs` table) recording timestamps and user IDs.

### 2.3 Supabase Multi-Factor Authentication (TOTP / AAL2)

- **Opt-In Security Model**: Authenticator app enrollment is optional for members and staff seeking an extra layer of protection (AAL1 remains default; enrolled users step up to AAL2).
- **Visual QR Code & Secret Key Display**: Generates an SVG QR code compatible with Google Authenticator, 1Password, Authy, Apple Keychain, and Microsoft Authenticator, with one-click secret key copy.
- **Challenge Verification**: Enforces enrollment activation only after verifying a valid 6-digit TOTP challenge code.
- **Factor Management**: Displays active enrollment status with enrolled timestamp and provides secure factor unenrollment.
- **Step-Up Authentication Flow**: Created `/mfa-verify` route that intercepts logins when `nextLevel === 'aal2'`, prompting for the 6-digit TOTP code before granting access to protected dashboards.

### 2.4 Strict Least-Privilege RBAC Hardening

- **Settings Isolation**: Restricted `/admin/settings` and server actions (`updateSiteSettingsAction`, `updateContactSettingsAction`) exclusively to users holding the `settings.manage` permission (`admin` role only).
- **Separation of Duties**: Non-admin staff (e.g. `editor`, `treasurer`) are strictly blocked from sensitive API configurations and global club settings while retaining full access to their respective operational domains.
- **Defense in Depth**: Enforced across three layers:
  1. Next.js Server Actions authorization guards
  2. Database Row-Level Security (RLS) policies
  3. Route-level middleware redirection
