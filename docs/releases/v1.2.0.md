## 1. Executive Summary

Version **v1.2.0** marks the formal launch of the Saugatuck Douglas Garden Club (SDGC) platform into **live production on Vercel** (`https://sdgc.redwan.work/`).

This release incorporates full Cloudinary CDN media delivery, polished navigation and branding typography, remote database seed migrations for core public pages, remote Supabase RBAC account provisioning, and establishes the strict Branch & Pull Request workflow for all ongoing development.

---

## 2. Release Highlights & Deliverables

### 2.1 Cloudinary CDN & Universal Media Architecture

- **Dual-Provider Architecture**: Architected a seamless media layer (`src/lib/storage.ts` & `src/lib/cloudinary.ts`) supporting both Supabase Storage and Cloudinary CDN.
- **Dynamic Signed Uploads**: Implemented `/api/media/cloudinary-sign` for secure, tamper-proof client-side asset uploads with staff-only role verification.
- **Automatic Optimization**: Enabled Cloudinary format and quality optimization (`f_auto,q_auto`), responsive width stepping, and WebP/AVIF delivery across all historical and current garden club media assets.
- **Zero Asset Breakage**: Migrated all 90+ historical assets to Cloudinary cloud `p4wempwi` under the `sdgc-web` namespace, with public CDN fallbacks ensuring 100% route image resolution.

### 2.2 Public Header & Brand Experience Polish

- **Navigation Clarity**: Streamlined header links to concise labels: `About`, `Garden Walk`, `Events`, `Gallery`, and `Contact`.
- **Button Dimension Normalization**: Standardized heights, padding, and font metrics between primary CTA buttons ("Become a Member", "Login") and the Dark/Light theme toggle for visual rhythm and alignment.
- **Enhanced Crest Emblem**: Integrated responsive SDGC heritage crest with SVG crispness and brand-aligned serif/sans typography.
- **Dynamic CMS Fallbacks**: Deployed remote database migration `20261018210000_seed_core_pages.sql` to populate `/about`, `/garden-walk`, and all club history in remote Supabase, backed by resilient server-side fallbacks.

### 2.3 Role-Based Access Control (RBAC) Accounts

- **Remote Production Accounts Provisioned & Verified**:
  - `admin`: Full administrative control over member rosters, annual dues, role assignments, and site settings.
  - `editor`: Granular authority over events, calendar schedules, photo gallery, and content pages.
  - `treasurer`: Direct access to financial reconciliation, member dues audits, and payment records.
  - `member`: Active membership status, authenticated member directory access, and profile management.
- **Atomic Role Transitions**: Enforced PostgreSQL `public.set_user_roles()` stored procedures with SECURITY DEFINER and transactional rollback protection.

### 2.4 Administrative & Member Portal Enhancements

- **Accessible Dialog Suite**: Reusable `AccessibleDialog` components with focus trapping, ESC key listener, and ARIA compliant roles.
- **Member Dues & Term Tokens**: Real-time status indicators (Active, Overdue, Lapsed, Lifetime) with audit logs and filterable overview counters.
- **Event Lifecycle Controls**: Added venue selector, status toggles (Scheduled, Cancelled, Completed), Detroit timezone wall-clock preservation, and ICS calendar feeds.
