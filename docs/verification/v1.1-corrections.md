## 2. User-Reported UI Modernization & Workspace Shells

### 2.1 Header Normalization & Mobile Drawer Fix

- **Problem**:
  1. The public header contained duplicate actions (`/join` in navigation links and "Become a Member" button on top right).
  2. Mobile drawer failed to render or appeared blank on physical device testing (iPad Pro 11-inch & Pixel 9 Pro Firefox).
- **Files Touched**:
  - [`src/components/layout/site-header.tsx`](file:///J:/DevDrive/sdgc/src/components/layout/site-header.tsx)
  - [`src/components/layout/mobile-navigation.tsx`](file:///J:/DevDrive/sdgc/src/components/layout/mobile-navigation.tsx)
- **Solution & Implementation**:
  - Removed `/join` from `NAV_LINKS`. Primary navigation now contains content routes only: _Home, About Our Club, Garden Walk, Events, Gallery, Contact Us_.
  - Preserved single primary call-to-action button on top right: `Become a Member` alongside `Login` and `ThemeToggle`.
  - Re-architected `MobileNavigation` using a React 19 portal rendering directly to `document.body` (`createPortal`), wrapped in a high `z-[100]` stacking context, backdrop blur (`backdrop-blur-md bg-background/80`), focus trapping, Escape key handling, and touch targets.

### 2.2 Dedicated Workspace Shells (No Public Header/Footer in Dashboards)

- **Problem**:
  - Logged-in admin and member portals displayed public site headers (`SiteHeader`) and public footers (`SiteFooter`), creating visual clutter and departing from modern dashboard standards (e.g. JnUITS operator workspace).
- **Files Touched**:
  - [`src/app/(admin)/admin/layout.tsx`](<file:///J:/DevDrive/sdgc/src/app/(admin)/admin/layout.tsx>)
  - [`src/features/admin/components/admin-shell.tsx`](file:///J:/DevDrive/sdgc/src/features/admin/components/admin-shell.tsx)
  - [`src/app/(member)/layout.tsx`](<file:///J:/DevDrive/sdgc/src/app/(member)/layout.tsx>)
  - [`src/features/membership/components/member-shell.tsx`](file:///J:/DevDrive/sdgc/src/features/membership/components/member-shell.tsx)
- **Solution & Implementation**:
  - Completely removed `SiteHeader` and `SiteFooter` from `AdminLayout` and `MemberLayout`.
  - Implemented `AdminShell` and `MemberShell` providing dedicated operator workspaces: sidebar navigation with icons, top header bar displaying current section title, user email badge, theme toggle, and direct "View Public Site" escape hatch.

## 3. Codex Audit Matrix & Corrections Evidence (V11-01 to V11-11)

### V11-01: Financial Simulation & Webhook Boundary

- **Files Touched**:
  - `src/features/payments/stripe-provider.ts`
  - `src/app/api/webhooks/stripe/route.ts`
  - `supabase/migrations/20261017050113_security_and_audit_boundaries.sql`
  - `tests/integration/remediation-r6.test.ts`
- **Mechanism**:
  - Webhook handler fails closed (HTTP 400) if `STRIPE_WEBHOOK_SECRET` is missing.
  - Computes HMAC-SHA256 signature and rejects forged/stale signatures.
  - Enforces `payment_status === "paid"`, matches expected amount and currency from existing payment record.
  - Separates `provider_session_id` (`cs_*`) from `provider_transaction_id` (`pi_*` / `ch_*`) in schema and updates.
  - Provider URLs for unconfigured Stripe return clear, disabled stubs rather than constructing fake Stripe URLs.
- **Verification**:
  - `tests/integration/remediation-r6.test.ts` (19 tests) verifies forged signatures return 400, unpaid completions are rejected, and valid signatures transition state idempotently.
